# Private compatibility fixtures

Put your own `.gp3`, `.gp4` and `.gp5` files here to test compatibility with real-world songs.

Everything in this directory except this README is git-ignored, so these files stay on your machine and never enter repository history.

When files are present:
- `npm test` round-trips each one through the document model and checks that the played notes are identical to alphaTab's direct import.
- `npm run test:e2e` uses `Tower10.gp5`, if present, for a large-file open/edit latency check.

When the directory is empty, those checks are skipped. The deterministic, redistributable fixtures used by every test run live in `fixtures/` (generated by `scripts/make_fixtures.py`).
